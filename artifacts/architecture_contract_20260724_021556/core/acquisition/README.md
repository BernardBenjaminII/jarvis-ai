# JARVIS Acquisition Engine

The Acquisition Engine determines **what knowledge JARVIS should acquire** before it enters the Knowledge Engine.

Its responsibilities include:

- Discovering sources
- Evaluating trustworthiness
- Ranking candidate sources
- Recording provenance
- Evaluating licensing
- Determining whether content should be assimilated

The Acquisition Engine feeds the Knowledge Engine.

Knowledge Flow:

Internet
    ↓
Acquisition Engine
    ↓
Receiving
    ↓
Knowledge Engine
