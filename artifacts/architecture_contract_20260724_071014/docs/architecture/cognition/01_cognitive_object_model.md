# Genesis IV-R1 Cognitive Object Model

The Cognitive Object Model is the immutable substrate for future cognition layers.
It supplies identity, UTC timestamps, confidence, lifecycle, provenance, evidence
and justification references, authority, attributes, canonical serialization, and
deterministic hashing.

R1 is additive. Existing Observation, Evidence, and Claim APIs are unchanged.
Concrete layer adoption requires later layer-specific adapters and certification.
