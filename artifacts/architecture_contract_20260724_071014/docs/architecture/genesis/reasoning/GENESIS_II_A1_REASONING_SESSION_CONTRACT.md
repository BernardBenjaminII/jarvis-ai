# GENESIS II-A1 — REASONING SESSION CONTRACT

**Document ID:** GENESIS-II-A1  
**Status:** Implemented  
**Subsystem:** Reasoning  
**Scope:** Immutable managed-session contracts  
**Constitutional dependency:** Genesis I Reasoning Architecture Certification

---

# Objective

Genesis II-A1 introduces the constitutional contracts required to represent a
managed reasoning session.

This phase does not introduce session execution.

This phase does not modify the certified `ReasoningEngine`.

This phase establishes the stable vocabulary upon which later session
lifecycle, governance, persistence, replay, and executive integration may be
built.

---

# Architectural Boundary

```text
Executive Governance                  Future Genesis II phases
        │
        ▼
ReasoningSession                      Genesis II-A1
        │
        ▼
ReasoningEngine                       Certified Genesis I
```

`ReasoningSession` describes a managed reasoning activity.

`ReasoningEngine` performs deterministic reasoning.

The session contract does not execute, supervise, persist, or authorize
reasoning.

---

# Canonical Contracts

## ReasoningSessionId

A UUID-backed stable session identity.

The contract supports validation of existing UUID values, deterministic UUIDv5
derivation, and stable string representation.

The contract does not create random identifiers. Identifier allocation policy
belongs to future executive governance.

## ReasoningSessionState

The canonical lifecycle vocabulary:

```text
CREATED
INITIALIZED
COLLECTING_EVIDENCE
REASONING
REVIEW
COMPLETED
FAILED
CANCELLED
```

Genesis II-A1 defines names only. Genesis II-A2 will define permitted
transitions.

## SessionAttribute

An immutable key-value metadata attribute.

Ordered tuples are used instead of arbitrary dictionaries to preserve stable
equality, serialization, and architectural fingerprints.

## ReasoningSessionMetadata

Immutable contextual metadata containing:

- Creating authority
- Optional mission identity
- Optional objective identity
- Optional correlation identity
- Deterministically ordered attributes
- Contract schema version

## ReasoningSession

An immutable session snapshot containing:

- Session identity
- Session metadata
- Current lifecycle state
- Monotonic revision number

Future lifecycle operations shall create new snapshots rather than mutate
existing snapshots.

# Constitutional Invariants

1. Session contracts are immutable.
2. Session identity is explicit.
3. Identifier derivation is deterministic.
4. Metadata ordering is deterministic.
5. Duplicate metadata keys are forbidden.
6. Session revision is non-negative.
7. Session state uses a closed canonical vocabulary.
8. No wall-clock time is generated by the contract.
9. No random identifier is generated by the contract.
10. No network, process, persistence, or model execution occurs here.
11. The session package does not import or wrap `ReasoningEngine`.
12. Executive authority is not embedded in the data contract.

---

# Deferred Responsibilities

The following responsibilities are intentionally deferred:

- Lifecycle transition policy
- Session creation service
- Session repository
- Checkpointing
- Replay
- Budget enforcement
- Human review workflow
- Executive authorization
- ReasoningEngine invocation
- Outcome calibration
- Learning feedback

Introducing any deferred responsibility in II-A1 would violate phase scope.
