# JARVIS Architecture Decision Records

This directory contains the official Architecture Decision Records (ADRs) for JARVIS.

## Naming Convention

```
ADR-####-short-kebab-case-name.md
```

Example:

```
ADR-0017-bootstrap-lifecycle.md
```

Rules:

- ADR numbers are never reused.
- ADR numbers are never renumbered.
- Existing ADRs remain unchanged for historical integrity.
- New ADRs always receive the next available number.
