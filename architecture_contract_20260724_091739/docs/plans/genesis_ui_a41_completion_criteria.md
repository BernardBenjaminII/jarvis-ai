# Genesis UI-A4.1 Completion Criteria

- [ ] A canonical `knowledge` projection provider exists.
- [ ] The provider is registered in the default runtime.
- [ ] The configured knowledge root is projected.
- [ ] Missing roots report `not_configured`.
- [ ] Unreadable roots report `unavailable`.
- [ ] SQLite stores are opened read-only.
- [ ] Database names, sizes, tables, and row counts are projected.
- [ ] Filesystem totals and top-level distribution are projected.
- [ ] Filesystem scanning is bounded.
- [ ] Inventory results are cached.
- [ ] Inventory state has a deterministic fingerprint.
- [ ] UI-A3 regressions pass.
- [ ] No ingestion, mutation, or remote execution endpoint is introduced.
