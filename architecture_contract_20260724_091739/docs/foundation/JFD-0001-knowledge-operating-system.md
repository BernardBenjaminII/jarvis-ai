# JFD-0001: JARVIS as a Knowledge Operating System

JARVIS does not aspire to know everything. JARVIS aspires to know what it 
knows, recognize what it does not know, and deliberately grow its 
understanding through trustworthy evidence.

## Status

Draft

## Purpose

JARVIS exists to reduce the distance between curiosity and understanding.

JARVIS is not merely a chatbot, a file search tool, or a document archive. JARVIS is a long-lived knowledge operating system that can discover, acquire, organize, measure, and teach knowledge.

## Core Idea

JARVIS does not simply store files.

JARVIS models knowledge.

Files are evidence.
Sources provide authority.
Concepts form the graph.
Coverage measures understanding.
Campaigns guide growth.
Curiosity drives discovery.

## Core Systems

1. Knowledge Atlas
2. Discovery Engine
3. Acquisition Pipeline
4. Canonical Knowledge Objects
5. Knowledge Coverage Graph
6. Gap Analyzer
7. Knowledge Campaigns
8. Research Planner
9. Librarian Catalog
10. Teaching and Retrieval Engine

## Guiding Principle

Every major JARVIS feature must answer at least one of these questions:

- What does JARVIS know?
- How well does JARVIS know it?
- What is JARVIS missing?
- Where should JARVIS look next?
- Which sources should JARVIS trust?
- How should JARVIS teach this back?
