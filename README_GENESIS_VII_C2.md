# Genesis VII-C2 — Constitutional Analysis Engine

## Install

From the JARVIS repository root:

```bash
unzip -o ~/Downloads/genesis_vii_c2_constitutional_analysis_engine.zip -d .
```

```bash
PYTHON_BIN=/media/abdullah/JARVIS_RUNTIME_L/venvs/ubuntu/bin/python \
./dev/install_genesis_vii_c2.sh
```

## Independent verification

```bash
PYTHON_BIN=/media/abdullah/JARVIS_RUNTIME_L/venvs/ubuntu/bin/python \
./dev/verify_genesis_vii_c2.sh
```

Genesis VII-C1 must already have produced:

`artifacts/audit/km0000-c1/constitutional_extraction.json`
