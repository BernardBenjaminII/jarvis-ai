# Executive Summary

The Executive Operating System shall possess a
permanent institutional memory that survives the
replacement of software, hardware, personnel,
organizations, and generations of technology.

Institutional Memory is the constitutional
repository of everything the institution has
observed, learned, decided, created, certified,
executed, and preserved.

Institutional Memory transforms historical records
into enduring organizational wisdom.

Accordingly, this document establishes the
Executive Asset Institutional Memory Standard.
