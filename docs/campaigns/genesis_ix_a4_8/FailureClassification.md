# Failure Classification Manual

Every failure receives exactly one primary classification.

| Code | Classification |
|---|---|
| `ARCH` | Architecture |
| `INTEG` | Integration |
| `RETR` | Retrieval |
| `QUAL` | Qualification |
| `GRND` | Grounding |
| `PROMPT` | Prompt |
| `LLM` | Model |
| `RUNTIME` | Runtime |
| `CONFIG` | Configuration |
| `DATA` | Data |
| `TELEM` | Telemetry |
| `UI` | Mission Control |
| `PERF` | Performance |
| `REG` | Regression |
| `OPERATOR` | Operator |
| `UNKNOWN` | Unknown |

Severity runs from `S1` cosmetic to `S4` mission-critical trust failure.
