# AB-0005: Curiosity Engine

## Status

Draft

## Purpose

The Curiosity Engine determines what JARVIS should learn next.

## Core Questions

- What do I know?
- What am I missing?
- What knowledge is stale?
- What knowledge is low-confidence?
- What prerequisites are weak?
- Which trusted source should I consult?

## Inputs

- Knowledge Coverage Graph
- Librarian Catalog
- Canonical Knowledge Objects
- Knowledge Atlas
- user goals
- active campaigns

## Outputs

- discovery plans
- acquisition missions
- campaign recommendations
- refresh recommendations
- learning path improvements
