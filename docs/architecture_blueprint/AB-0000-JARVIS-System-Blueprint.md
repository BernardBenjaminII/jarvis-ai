# AB-0000: JARVIS System Blueprint

## Status

Draft

## Purpose

This document is the master architectural map for JARVIS.

JARVIS is not merely a chatbot, file search tool, or document archive. JARVIS is a long-lived assistant platform built around a Knowledge Operating System.

## Core Mission

JARVIS exists to reduce the distance between curiosity and understanding.
