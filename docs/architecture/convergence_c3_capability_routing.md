# JARVIS Convergence C-3 — Capability Routing

C-3 establishes the canonical deterministic capability router between compiled operator objectives and the existing Director Registry.

The router uses objective text, explicit routing hints, Director capabilities, priority, and readiness. It may create several parallel delegated tasks for one objective. Every decision is persisted as routing evidence on the mission task.

C-3 does not add a second Director registry and does not invoke an LLM for routing. The existing registry remains authoritative.
