# Convergence C-5 — Executive Knowledge Awareness & Evidence Reasoning

C-5 activates the existing Knowledge Catalog, grounding, evidence, and deterministic reasoning architecture as one Executive capability.

The canonical path is:

`operator request → catalog grounding → evidence normalization → coverage assessment → hypothesis reasoning → answerability → research recommendation → executive synthesis`

C-5 does not replace the catalog, assimilation pipeline, or reasoning engine. It adds the executive knowledge-state projection that allows JARVIS to state what it knows, how well it knows it, what evidence supports it, and what should be acquired when knowledge is insufficient.

## Invariants

- No evidence is invented.
- Every reasoning assessment retains a deterministic fingerprint.
- Missing evidence becomes an explicit research recommendation.
- Knowledge awareness is metadata and traceable context, not hidden prompt behavior.
- The assimilation pipeline remains the owner of acquisition and ingestion execution.
