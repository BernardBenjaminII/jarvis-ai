# Genesis IX-0 — JARVIS Operational Integration

Genesis IX-0 turns the certified Government Framework and Organizational Registry into a visible runtime. It boots Government, starts a real heartbeat, computes readiness and health, atomically publishes `artifacts/runtime/jarvis_operational_state.json`, and accepts `reload_registry`, `take_snapshot`, `show_health`, and `stop`.

Run with:

```bash
PYTHON_BIN=/path/to/python ./dev/run_jarvis_operational.sh
```

Acceptance requires visible boot output, recurring cycles, a live state artifact, and execution of a real runtime command.
