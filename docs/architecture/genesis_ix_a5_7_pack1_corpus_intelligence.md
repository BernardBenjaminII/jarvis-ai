# Genesis IX-A5.7 Pack 1 — Corpus Intelligence Framework

## Mission

Create the canonical reusable inventory of every SQLite-backed corpus visible
to JARVIS before metadata quality, vocabulary, hierarchy, propagation, or
retrieval intelligence is evaluated.

## Safety

The framework validates SQLite headers, opens verified databases in read-only
mode, classifies invalid candidates without aborting, and performs no migration,
write, materialization, or reindexing.

## Products

It records database candidates, verified databases, tables, views, indexes,
triggers, FTS stores, row counts, inferred roles, observed pipeline stages,
foreign keys, runtime document-to-chunk relationships, and chunk-to-FTS
relationships.

Pack 2 will use this inventory to measure metadata population and formatting.
