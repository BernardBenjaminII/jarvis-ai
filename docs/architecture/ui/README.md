# JARVIS Mission Control UI

This directory contains the canonical architecture and experience
specifications for the JARVIS Gen 2 Mission Control interface.

JARVIS is not designed as a chatbot with additional tools.

JARVIS is a mission-oriented intelligence operating environment whose user
interface exposes system state, active missions, operational activity,
diagnostics, knowledge capabilities, and required decisions.

## Architectural status

The documents in this directory define the approved architectural baseline
for the Mission Control UI.

Implementation must not silently contradict these documents.

Material changes to the UI philosophy, primary layout, startup briefing,
SITREP behavior, or frontend state contract require an explicit architecture
revision.
