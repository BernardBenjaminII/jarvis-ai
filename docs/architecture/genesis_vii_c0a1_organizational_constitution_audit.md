# Genesis VII-C0A-1 — Organizational Constitution Audit

**Status:** Implemented
**Purpose:** Determine whether JARVIS already possesses a canonical Organizational Constitution before creating a new one.

The audit searches constitutional documents, architecture and ADR material, Executive implementation, routes, and Mission Control. It classifies the result as `already_exists`, `partially_exists`, or `does_not_exist` and writes evidence-linked JSON and Markdown reports under `artifacts/audit/`.
