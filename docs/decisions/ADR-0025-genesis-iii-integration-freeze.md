# ADR-0025 — Freeze the Genesis III Cognitive Workspace

**Status:** Accepted  
**Decision:** Genesis III-F1

## Context

Genesis III-A1 through III-A4 establish the cognitive workspace foundation, persistence, catalog/search, and integration engine. Future executive cognition will depend on these contracts. Uncontrolled changes to this layer would create hidden compatibility and reasoning risks.

## Decision

Freeze Genesis III with a deterministic, repository-local certification baseline covering:

1. canonical package identity;
2. stable public API exports;
3. permitted dependency direction;
4. complete module checksums;
5. regression verification for A1 through A4;
6. an architecture fingerprint and executive-readiness report.

The baseline is generated by `dev/tools/audit_genesis_3f1.py` and enforced by `dev/verify_genesis_3f1.sh`.

## Consequences

- Architectural drift becomes visible and fails verification.
- Public API changes require explicit baseline regeneration and review.
- Executive cognition can consume Genesis III through a stable boundary.
- The freeze does not prohibit evolution; it makes evolution deliberate, inspectable, and versioned.
