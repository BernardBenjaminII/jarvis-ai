ADR-0004

Decision

Doctor will use automatic plugin discovery.

____________________________________________________________________________
Reason

Avoid maintaining a manual registry as health checks grow.
____________________________________________________________________________
Consequences

Positive:
- Zero-maintenance plugins
- Easier extension
- Cleaner architecture

Negative:
- Slightly more startup complexity
