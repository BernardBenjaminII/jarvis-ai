# Genesis X-B — Knowledge Retrieval & Search Certification
Read-only baseline certification of the fully materialized runtime corpus.

Gates: SQLite integrity, chunk/FTS parity, duplicate paths, orphan chunks,
FTS query execution, benchmark coverage, latency, document diversity, provenance.

This phase deliberately changes no ranking or retrieval behavior. It measures
the current substrate before hybrid retrieval, embeddings, reranking, metadata
weighting, or query expansion are introduced.
