- [ ] Public `core.integration` imports succeed.
- [ ] Duplicate projection identifiers are rejected.

- [ ] Existing Operations endpoints remain available.
- [ ] New projection endpoints are available.
- [ ] Structural, compilation, unit, smoke, and UI-A1 regression checks pass.
