# Genesis UI-A3 Completion Criteria

- [ ] Seven real Operations capabilities register automatically.
- [ ] Built-in registration is idempotent.
- [ ] Capability metadata distinguishes bound and unbound state.
- [ ] Package roots are discovered recursively.
- [ ] Registration hooks execute deterministically.
- [ ] Import and registration failures are projected.
- [ ] Capability projection includes binding counts.
- [ ] Capability projection includes discovery statistics.
- [ ] Operations health maps `state=healthy` to `available`.
- [ ] No remote execution endpoint is introduced.
- [ ] UI-A2 and UI-A1 regressions pass.
