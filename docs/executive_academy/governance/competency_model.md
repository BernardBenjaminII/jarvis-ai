# Competency Model

A competency represents demonstrable, scoped ability—not mere document
availability.

## States

- Unknown
- Planned
- Developing
- Assessed
- Certified
- Restricted
- Expired
- Revoked

## Required Dimensions

- Domain scope
- Jurisdiction scope
- Authority coverage
- Source freshness
- Curriculum completion
- Assessment evidence
- Known gaps
- Certification version
