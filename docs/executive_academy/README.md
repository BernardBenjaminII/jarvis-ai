# Executive Academy

**Program:** Executive Academy Foundation  
**Current phase:** EAF-001 — Constitutional Foundation  
**Status:** Constitutional baseline  
**Runtime state:** Dormant

The Executive Academy is the educational, competency, and certification
institution of JARVIS.

Genesis builds the Executive Operating System. The Executive Academy defines
how that operating system becomes educated, measured, qualified, and certified.

EAF-001 intentionally introduces no services, routes, schedulers, persistence
engines, ingestion pipelines, or user-interface behavior. It establishes only
constitutional documents, canonical registries, schemas, static contracts,
tests, and deterministic verification.
